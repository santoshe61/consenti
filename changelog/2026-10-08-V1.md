The first-run setup wizard failed on the MySQL/MariaDB driver: `POST /setup/seed-profiles` returned `500 {"details":"Not implemented"}` because the MySQL adapter stubbed out template storage, which default-profile seeding depends on. The MySQL adapter now implements the full storage contract.
