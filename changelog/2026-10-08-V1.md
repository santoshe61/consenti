## [0.3.1] - 2026-10-08
### Summary
The first-run setup wizard failed on the MySQL/MariaDB, PostgreSQL and MongoDB drivers: `POST /setup/seed-profiles` returned `500 {"details":"Not implemented"}` because those adapters stubbed out template storage, which default-profile seeding depends on. All three adapters now implement the full storage contract.
### Added
- `@consenti/api`: MySQL, PostgreSQL and MongoDB adapters — consent/UI template CRUD, `listProfilesSummary`, `findProfilesUsingConsentTemplate`/`findProfilesUsingUITemplate`, and `getOptInStats`
### Changed
- `@consenti/api`: shared profile-summary and opt-in tally logic in `storage/derived-queries.ts` (used by the three adapters above)
### Fixed
- `@consenti/api`: MySQL/MariaDB, PostgreSQL, MongoDB — setup wizard "Install & continue" (seed-profiles) no longer fails with "Not implemented"; Templates, Profiles list and Opt-in stats pages work on these drivers
### Breaking changes
None.
### Migration
None. Schema already contained `consent_templates` / `ui_templates` on fresh installs.
