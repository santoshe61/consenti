## [0.4.0] - 2026-10-08
### Summary
`profileOverride` can now replace a whole keyed map in one line with the wildcard `'*': null`, instead of nulling every built-in key one by one. Built-in profiles use different button ids (`reject-optional`, `save-choices`, `manage-preferences`, …) across three `buttons` maps (`mainBanner`, `gpcBanner`, `preferenceModal`), so supplying custom buttons previously left the built-in ones showing next to them unless every id was nulled explicitly. The same wildcard works on `preferenceModal.categories` (and `cookies`), and under `complianceGroupsOverride` and `setProfile()`.
### Added
- `@consenti/ui`: `'*': null` wildcard delete in profile overrides — deletes every base key of that map the override doesn't name; named keys are kept and merged onto their base value (so `'accept-all': { text }` keeps its style/action/cookies), new keys are added. Works per map, so each surface can be replaced independently.
- `@consenti/ui`: dev warning (via the configured logger, `warning` level) when, after overrides, `mainBanner`/`gpcBanner` offers an "accept all" button but no reject (`cookies: '!'`) or `manage` button (GDPR Art. 7(3); CNIL/EDPB equal-prominence guidance). Hidden by default; enable with `verbose: true` or `core.console: ['warning']`.
### Changed
- `@consenti/ui`: `setProfile()` now keeps its patches as an ordered list and replays them on the resolved profile instead of folding each patch into `config.profileOverride` with `deepMerge`.
### Fixed
- `@consenti/ui`: `setProfile({ … key: null })` called after an earlier override lost its `null` delete (patch-onto-patch merge consumed the marker before it reached the profile). Deletes in later `setProfile()` calls are now honoured.
- `@consenti/ui`: a profile override whose base has no object at that key (e.g. `gpcBanner` buttons when the base profile has no `gpcBanner`) no longer leaks `null` markers into the result as real entries.
### Breaking changes
None. `'*'` is now reserved as a key in keyed profile maps (buttons, categories, cookies) — an id of literally `*` in those maps would previously have been a normal entry.
### Migration
None. Existing `{ key: null }` overrides behave as before.
